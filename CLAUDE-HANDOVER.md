## The one thread left

### CLI polish

The reframe worth holding while doing it: the CLI is the **reference client**, not a scratch
tool. Whatever it can do sets the floor for the Phase 2 API, so this is partly specification.

- **`tokens` does not print rank numbers**, but `branch <span> <index> <rank>` takes one — so
  today you count columns to use the command. Sharpest usability edge.
- **The cursor should mark its position inline** in the rendered text, not just with ` ←` at
  the end of the run line. Wrinkle: that line truncates at 68 characters, so the mark has to
  survive truncation — probably by windowing the shown text around the cursor rather than
  always from the start.
- **Batches are recorded and nothing reads them.** Every span carries `batch b0[2]`; no
  command groups or filters by it. The batch id was pulled forward into Phase 1 precisely so
  a batch could be read back as the experiment it was, and that payoff is uncollected.
- **No way to list parameter sets.** The intern table is invisible except one span at a time.
- More will surface in use — Daniel expects this and it is the point of doing the pass.

## What closing the others turned up

**`CONTEXT` was dead code, and the fix changed `core/llama.py`.** The response's `truncated`
flag was read as "the server cut the prompt" and raised on; it actually means generation hit
the context wall, which is the one thing `CONTEXT` is for. An over-long prompt is not
truncated at all — llama-server refuses it with HTTP 400. Both halves are now tested, and
`llama_test.py:context_limit` needs a second server:

    CTX=512 PORT=8082 scripts/llama-server.sh --n-gpu-layers 0

It skips rather than fails when nothing is on 8082. CPU-only because a second GPU instance
does not fit in 8GB beside the first. The rest of `llama_test.py` uses the ordinary 8081.

**Stop strings can silently eat generated bytes**, and the decision was to record it rather
than fix it. `FORMAT.md`, "A stop string can eat generated bytes". The real fix is matching
on token ids, which is the `BEYOND-MVP.md` token-replay path — the same fix as the
generation-point-inside-a-character limitation, which is why they are now written up
together in `CLAUDE.md`'s open threads.

**`data/tree/` is a stale-format tree** and now refuses to load, which is correct and was the
first live exercise of the no-migration policy. It is disposable scratch; delete it and
`loom.py new` when it is next wanted.

**The old `data/*.json` trees are untouched** and belong to the old format. `data/local.json`
in particular is not disposable.
